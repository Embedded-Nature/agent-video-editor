# Posting a Short

Write it as `YOUTUBE.md` next to the render. Everything below is a pattern from one post that the channel signed off on; fill it from the transcript and the job, never with claims the footage doesn't show (no horsepower, no mileage).

## Title

The car first, then what was done to it. 40-50 characters; the feed cuts around 40, so the first half must stand alone. It says the same thing as the cover.

```
971 Panamera Turbo Gets a BMC Air Filter Upgrade
```

## Description

Written like the host talking, in the first person. The first sentence carries every search term (generation code, model, brand, part), because YouTube weighs the start most. One line to react to ("Look how dirty the old one was 😬"), the how-to's quirk as an aside, the full video's link, what's next, then three hashtags (YouTube shows up to three above the title).

```
Swapped the stock paper air filter on my 971 Panamera Turbo for a pre-oiled BMC. Look how dirty the old one was 😬 Twin turbos breathe through this thing, so it was time. Bonus: the BMC washes and goes back in, no more buying paper filters.

Fair warning, Porsche hid the air box behind the front bumper, so the bumper comes off. Full how-to here 👉 <full video URL>

Secondary cat bypass is next. Subscribe so you don't miss it.

#porsche #panamera #shorts
```

## Tags

Model, generation, brand + part, the job, "diy", "how to". They matter little on Shorts; they catch misspellings.

## Upload settings

| Setting | Value |
| --- | --- |
| Related video | The full how-to. A link in a Short's description isn't clickable in the feed; this is the link that gets taps. |
| Thumbnail | `cover.jpg` if the upload screen offers a custom image; otherwise a frame from the graded opening. |
| Audience | Not made for kids |
| Category | Autos & Vehicles |
| Altered or synthetic content | No for real footage and a `make_beat.py` bed (synthesised, not AI-generated). |
| Remixing | Allow |
| Playlist | With the full video |

## After it's live

- Pin a comment that asks people to pick a side ("Honest question: BMC, K&N, or just stick with paper on a turbo car? 👇").
- Link the Short near the top of the full video's description ("Quick version: <link>").
- Answer comments in the first hour.
- The same file and cover work as a Reel and a TikTok (type is inside the shared safe band); on TikTok say "link in bio".
- After 48 h, read "chose to view" in Studio. Low means the opening frame isn't stopping the swipe: change the first shot, not the title.
